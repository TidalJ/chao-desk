How to search	搜索方法
**Apps** — type part of the name, its initials or pinyin: `wx`, `weixin` and `微信` all find 微信; `vsc` finds Visual Studio Code.	**应用** — 输入名称的一部分、首字母或拼音：`wx`、`weixin` 和 `微信` 都能找到微信；`vsc` 能找到 Visual Studio Code。
**Files** — all words must be in the name. `ext:mp4;mkv` or `*.pdf` filter by type, `folder:` / `file:` by kind, and a word with a backslash (`work\report`) matches the whole path.	**文件** — 所有词都必须出现在名称中。`ext:mp4;mkv` 或 `*.pdf` 按类型筛选，`folder:` / `file:` 按种类筛选，带反斜杠的词（`work\report`）匹配完整路径。
**Also** — sums like `12*(3+4)`, web addresses, and Chao Desk commands (settings, clipboard, lock, exit).	**其他** — 计算式（如 `12*(3+4)`）、网址，以及 Chao Desk 命令（settings、clipboard、lock、exit）。
**Keys** — Tab switches All / Apps / Files · Enter opens · Ctrl+Enter shows it in its folder · Ctrl+Shift+Enter runs as administrator · Ctrl+Shift+C copies the path · Alt+1…9 opens a result.	**按键** — Tab 切换“全部 / 应用 / 文件” · Enter 打开 · Ctrl+Enter 在文件夹中显示 · Ctrl+Shift+Enter 以管理员身份运行 · Ctrl+Shift+C 复制路径 · Alt+1…9 打开对应结果。
